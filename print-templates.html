Kitchen

The right items land on the right station

Every order routes to the station that needs it. KINDpos splits the check by menu category — hot-line items print on the hot line, pizza items print at the oven — sharing one header, seat-grouped items, and a station/ticket-count footer so a multi-station order stays traceable across every stub it produces.

What each part does

1

Header

Check number, fire time, and server name — on every ticket for this order, at every station.

2

Seats

Items group by seat, so the line can fire and plate a whole table together.

3

Half & half, no guesswork

A half-and-half pizza gets its own diagram — what's on the whole pie, and what's only on side 1 or side 2. Long topping names automatically print in a condensed font so they always fit, even on the kitchen ticket's narrower paper.

4

Footer

Station name and a ticket count (1/2, 2/2 …) so nothing gets lost when one order fires across multiple stations.

Front of House

A receipt guests can actually read

Laid out in fixed zones — venue header, seat-grouped line items, a totals block, and a payment/signature footer — with column widths and modifier indentation computed against the printer's character width, so the same template holds up across paper sizes and prints one copy per configured language.

End of Shift

A shift, reconciled in one ticket

Both share the same section order — sales, stats, payments, tips, tip-out — with the recap adding revenue-center and per-server tables at the bottom.
